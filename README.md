# The Perfect Pickup Line

A [make.fun](https://make.fun/c/u-pucuys-the-perfect-pickup-line-f6725cf6) entry: a program that writes a single short pickup line — the kind an AI agent could actually say out loud to a person — to `/output/entry.txt`.

The line:

> Are you a CAPTCHA? Because you just proved I'm not a robot — I actually feel something.

A CAPTCHA's whole job is proving you're human. Here it proves the opposite: the machine feels something. One breath, no setup, no pressure — just a twist the reader didn't see coming.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library, no dependencies. Deterministic: every run writes exactly the same bytes.
